# Skills Manager management skill example

This is an opt-in repository example. It is not bundled into the Python
package and is never copied into an agent scope automatically.

Validate it from the repository root:

```sh
python3 -m skillsmgr validate --path examples/skills-manager-management --json
```

The portable skill instructions and explicit manual install/removal steps are
in [SKILL.md](SKILL.md). Review the whole file before installing it into one
user-selected scope.
