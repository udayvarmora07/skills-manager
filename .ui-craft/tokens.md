# Skills Manager UI tokens

These tokens are the persistent design decisions for the no-build frontend.

| Role | Light | Dark |
|---|---|---|
| Canvas | `#f5f6f8` | `#15181e` |
| Navigation rail | `#f0f2f5` | `#1b1f27` |
| Content surface | `#ffffff` | `#20252e` |
| Raised surface | `#f0f2f5` | `#282f3a` |
| Primary text | `#20242c` | `#edf0f5` |
| Secondary text | `#626b79` | `#a5afbd` |
| Border | `#dce1e8` | `#37404c` |
| Copper action | `#a94b20` | `#e7a06f` |

Font roles: `system-ui` for interface and document headings; `ui-monospace`
for paths, commands, and code. Feedback transitions are 150ms and all
non-essential animation is disabled for `prefers-reduced-motion: reduce`.
